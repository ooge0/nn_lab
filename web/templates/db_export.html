Every run generated through the UI or CLI is stored as JSONL files by default (the live JSONLStore). SQLiteRepo is a second, fully-tested Repository implementation over real SQLite tables (runs, responses) -- useful for ad-hoc SQL queries (see /docs or the Sphinx Operations page's "Inspecting results directly" section for real example queries). Sending a run here copies it into results/nn_lab.db; nothing about the source JSONL files is touched or deleted.
